短信转发 · 开关与规则
短信转发
默认关闭；关闭后停止独立转发进程。自动转发只处理启用后的新短信；历史补发需要另外预览和确认。地址和密钥不回显，修改普通规则会保留旧凭据。
转发目标
支持 Webhook、Bark 和 Telegram，最多8个。只在需要替换时重新填写地址和凭据；输入不会保存到浏览器草稿。
匹配规则
最多32条，所有筛选条件须同时满足；同一目标按第一条匹配规则发送一次。默认仅通知；可明确选择隐藏英数字或完整正文。高级条件支持有限正则和按短信标注时间判断的固定时区窗口。
保存和开关修改需要所有者最近5分钟内登录。已发出的第三方请求不能保证撤回；结果不确定时不会自动重发。关闭此配置区会清空尚未提交的地址和密钥。
历史短信补发 · 先预览再确认
仅补发所选范围中符合现有规则的短信；每批最多32条、64个递送。预览不会发送或开启转发；总开关已开启时才能确认。旧在途、未确认和已确认记录会跳过。
本机已保存的补发摘要
五分钟或设备服务重启后，未确认预览会失效；刷新只核对，不会重新发送。存在在途或Unknown时不能归档，先保留并核对。归档只清理批次索引，递送回执仍在设备上；浏览器先保留本批摘要。
一键测试转发
转发服务确认运行后，向一个已保存目标发送固定合成通知，不使用真实短信。只提交一次，短时自动核对回执。
