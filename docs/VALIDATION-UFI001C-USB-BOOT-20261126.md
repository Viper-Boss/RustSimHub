## 结论

正常 USB 设备由 `rustsimhub-usb.service` 注册。它在 `rustsimhub-firstboot.service` 之后启动，后者依赖已挂载的 `RSH_CONFIG` 和共享分区。当前迹象指向这条依赖链之前的启动阶段。要区分 LK 交接、内核启动和根分区挂载失败，需要采集开机 UART 日志。系统启动、USB 枚举与双槽切换仍待实机验证。
