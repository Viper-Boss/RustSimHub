# 只读身份/签名钥匙加载

实机加密恢复的密文/预期 pin/错钥匙/篡改/覆盖检查已通过，但随后 owner 登录因旧 simhubctl 的 ClientKey::load 以读写方式打开锁文件而失败。不能把这次部分结果写成全部恢复完成，也不改用可写挂载绕过。

现在 create 才可创建/以可写打开锁；load 只打开既有严格私有锁文件 O_RDONLY，仍保留 flock 排他与 seed 校验，缺失身份或锁不会创建任何文件。恢复到已验证新空目录时，由恢复工具显式创建自己的空私有锁，再加载新身份。当前使用只读接收者/owner mount 的验收须等新产物重新执行。

测试含只读种子、只读锁及 0500 目录、缺失身份不创建文件；完整恢复和普通签名/撤销用例继续执行。常驻 Auth 接口/角色/会话/签名 purpose 不变。
