## 故障回选与清理接口

- 启动缺软件/证明/出口时拒绝。不能自动换为普通蜂窝 APN、任意网卡、Root shell
  或其他正在运行的 daemon。USB 的既有授权入口保持原门禁。
- 部分/迟到启动或停止超时保留原证明与精确进程，Unknown 只查原资源；
  `resume_cleanup()` 只继续原范围，不能重发已发 stop、获得新租约或救活已取消运行。
- 统计提交可能发生后只查原摘要，重启、超期、跨窗口均不生成第二笔交易。
  缺持久化/可信结果不能称成功；只释放自己拥有的统计引用。
- SMTP 最终提交边界之后断线/超时为 Unknown，不重试；服务器接受只证明 SMTP 接受。
  邮件不能通过旧 HTTP 回执或未经审批的 queue schema 伪装已确认。
- 网页只读失败保留未知；页面刷新、关闭或切换设备不能自动重放旧业务请求。
  缺安全 provider 时保留关闭状态，不使用 Mock、蓝牙 bonding 或前端布尔值授予权限。

真实 Root/SDK/安全会话/邮件兼容接线获审并交付后，需重新运行整个组合。
C 再消费精确来源、架构/摘要/许可和经审 Root 材料组装；主线负责签名、部署、设备
退出/路由/网络和外部邮件/链验证。本候选没有签名、安装、开服务或生产发布动作。
