# NKN 与活跃安装统计：查询接线

本轮完成的是**显式汇总查询**，不是本设备的链上签到、续订或公网验收。统计仍称为“近期活跃安装估计”，不能称为人数、在线用户或 NKN 节点数。

## 实际入口

1. 原本地所有者登录。在 NKN 面板点击“启用统计只读查询”，沿用 `set_nkn_enabled`、独立 `statistics` 引用、浏览器 CAS 回执和当前 Core 上下文，请求原有限权限；不会开启 remote/manual 引用。
2. 点击“只读刷新统计”，发送 `usage_stats_query {token, window}`。只接受 `24h`、`30d`、`90d`；登录、重绘和状态轮询不会查询。
3. Core 复用 `usage-stats::QueryClient`：每窗口至少间隔 5 秒；失败、旧缓存、真实 0 分开表示。缓存只在当前进程内，换 realm 清除，不声称已持久恢复。
4. Core 仅向**已运行且仍有统计引用**的原 Root 注册创建观察连接。新增请求操作码 7/8/9，原 generation/nonce/policy/deadline 绑定不变。响应为原 87 字节快照加 `RSUC\x01 / u32长度 / JSON`，最多 2048 字节，不更新原证据或租约。
5. Root 的原 SDK 管道发送 `usage_24h/usage_30d/usage_90d`。状态和统计共享串行管道、帧序列和 1024 帧预算；单次查询不会关闭、重启共享引擎。每窗口 5 秒限频。
6. SDK 主机通过原 scoped dialer、Root UID 的原 nft 出口限制，向**固定已安装的第一个 HTTPS seed**执行一次 `getsubscriberscount`。主题固定为 `rustsimhub-usage-v1-{24h,30d,90d}`，`subscriberHashPrefix` 为空。不取订阅者名单，不使用身份或私钥。

## 安装前置与默认行为

- Core 仍需 `product-providers-candidate` 及原显式启动参数。默认构建不激活提供者。
- Root 固定策略新增可选 `"usage_query_protocol":1`；省略/0 拒绝查询，大于 1 拒绝策略。旧策略的省略序列化保持兼容。安装策略、真实 SDK/Root 和角色仍走可信维护流程，网页不能填网址、主题、命令、UID 或密钥路径。
- 保持原最长 300 秒 Root 授权，不自动续权或后台启动。最后一个统计引用关闭时走原清理；其他 remote/manual 引用仍在时不会停止共享进程。
- SDK HTTP 总时限 1 秒、Root 管道 1.5 秒、Core 观察最多 2 秒，统计库总预算仍为 10 秒。HTTP 禁用代理、重定向、连接复用及自动重试；正文读取至多 2049 字节后拒绝超限。
- 缺字段、null、重复字段、错误 ID/窗口、负数、小数、超限、附加文档均不会变为 0；原始 RPC 错误文本不向网页回显。
- 此开关只管理**查询运行引用**，不能解释为未来“参与安装上报”的同意，不创建统计身份、签名、订阅或续订。
- 退出、隐藏/离开页面取消读取并丢弃迟到结果；配网和一键通话测试等占用期间禁用读取。Core 请求前后核原 Owner，查询与 statistics-off 串行，不持 Auth 锁执行网络 IO。

## 剩余生产接线

独立参与同意、当前隐私声明确认和原Owner接口已补齐，见[参与授权接线](usage-participation-integration.md)。目前只保存许可，不创建身份或启动上报，不是永久Root授权。

1. 把独立统计身份、真实签名交易准备/摘要与现有持久 `CheckInManager` 接到受限签名端口。
2. 单次订阅提交、掉线/崩溃后按原摘要查询确认、关闭中的迟到响应代次核对；HTTP 返回/摘要生成不等于链上成功。
3. 单独审核长期开启和续订政策，不能悄悄扩大当前 300 秒本地 Owner 授权。
4. 核对固定 HTTPS seed、产品包和回退，在本次设备写入及真实链上交易授权后实测。Wi-Fi/USB 失败不得切换普通蜂窝 APN。

本轮未写设备、未生成或安装新 epoch、未取 Owner/SIM 私钥、未请求公网 NKN 或发送交易；另一窗口 AirSIM 蓝牙文件保持原样。
