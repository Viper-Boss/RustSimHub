# 通信中心、短信转发与数据漫游

通信中心提供收件箱、验证码和回收站。收件箱可全选已加载的短信，也可按当前设备快照将整箱移入回收站。回收站可恢复所选记录，清空需确认具体数量。批量操作由近期登录的所有者提交，一批在同一数据库事务中执行。

清空回收站会清除棒子本地记录的发件人、时间、正文和二进制内容，保留防重复导入所需的来源及摘要。旧版仍会把清理记录视为已删除，数据库保护拒绝恢复。清理范围为棒子本地回收站。独立转发回执、历史备份、SIM 记录和外部已收到的副本遵循各自的管理流程。

左侧「短信转发」打开原有的规则、开关及回执面板。模拟测试使用隔离的 HTTPS 接收端和合成短信。已验证单次投递、默认遮蔽、保留不确定结果和关闭状态不创建工作进程。应用 89 实机只读核对到转发关闭及 MainPID 为 0。真实转发目标另待验收。

硬件状态的四个圆环按实际数值显示彩色弧线。在 Firefox 桌面与手机宽度下，验证环形样式、验证码筛选、批量删除与恢复、清空确认、转发入口和漫游按钮交互。

「SIM与调制解调器」里的国际数据漫游控制一份已配置、未连接且关闭自动连接的普通蜂窝数据配置。开启需先确认费用提示，再在第二步勾选并确认。服务端限制为近期所有者会话，有效期内一次性确认，绑定当前 SIM 与配置。完成后回读 NetworkManager 的 `gsm.home-only`；没有合适的数据配置时显示不可用。该开关适用于蜂窝数据，通话、短信及运营商套餐仍由运营商处理。测试只使用模拟数据，未开启蜂窝数据或产生漫游流量。

参考 [NetworkManager GSM 连接属性](https://www.networkmanager.dev/docs/api/latest/settings-gsm.html)。
