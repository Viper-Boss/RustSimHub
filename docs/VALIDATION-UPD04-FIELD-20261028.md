# UPD-04 实机验证：候选失败后整组回退（2026-10-28）

用户批准：“暂存 epoch 56 试运行，我在候选期间发一条短信到设备，你用 SIGKILL 杀 Core 触发自动恢复回退到 55，接受本次开机的自动恢复预算被用掉”。

## 做法

不制作坏程序。候选在“确认”之前出了故障，应用组就会被重启，选择逻辑会丢弃候选、回到已确认组，所以直接走真实的失败恢复路径：Core 异常退出 → systemd `OnFailure` → `rustsimhub-app-recover`（每次开机最多一次）→ 重启应用组 → 回到已确认组。开始前只读确认：core、edge、media 都是 `Restart=no`，都配置了 `OnFailure=rustsimhub-app-recover.service`，本次开机还没有用过恢复。

1. **候选**：epoch 56，与应用 54/55 同源（`552936b`）、同一批构建产物，用设备信任密钥重新签名。签名后用真实 ARM 更新器验签通过，3 个反例都被拒绝；上传后在设备上验证通过；做了停机持锁业务备份。
2. **暂存并试运行**：在停机窗口中用 `admit-stage` 暂存（退出码 0，三方兼容），重启应用组后，选择单元开始试运行 56（`attempted=true`）。逐项核对：正在运行的 Core、edge、音频都是 56 的签名程序，capabilities 为空，身份不变，转发关闭，恢复预算还没用。
3. **候选期间的新数据**：用户用手机给设备发了一条短信。只读复制数据库核对，收件箱从 95 条变成 96 条。
4. **注入失败**：`systemctl kill -s KILL rustsimhub-core`，只执行这一次。

## 结果

| 项目 | 结果 |
|---|---|
| systemd | Core `code=killed, status=9/KILL`，`Failed with result 'signal'`，触发 `OnFailure` |
| 自动恢复 | `rustsimhub-app-recover` 运行一次，写下 `/run/rustsimhub-app/recovery.used`（`RustSimHub.AppRecovery.v1`），然后重启应用组 |
| 回退 | 约 4 秒后，选择单元选中已确认的 epoch 55；`state.json` 为 `confirmed=55`、`candidate=null`、`attempted=false`、`floor=56` |
| 程序 | 正在运行的 Core、edge、音频都是 epoch 55 的签名程序，capabilities 为空，`NoNewPrivs=1` |
| 业务数据 | 收件箱 96 条，候选期间收到的那条仍在；删除标记 0 条（与之前一致）；有效所有者 1 个；Core 身份与回退前一致 |
| 其他 | PCM 全部关闭，蜂窝数据断开，没有失败单元，转发没有运行 |
| 恢复次数 | 1 次（本次开机的恢复预算已用掉，下次重启设备后恢复） |

验收条件“回到精确兼容组；Owner、短信、删除标记和授权保留；恢复次数真实记录”逐条满足。**UPD-04 记为完成。**

注意：重启设备之前，如果应用组再次出现故障，**不会再自动恢复**，需要人工处理。floor 已升到 56，以后的候选要从 epoch 57 开始。

## 顺带观察：LED-06 升级紫色

暂存开始后，录了 3 分钟灯：紫色每 6 秒一个周期（约亮 2 秒、灭 4 秒，`101` → `000`），一直持续到候选被处理。紫色熄灭时偶尔出现几十毫秒的 `100`，这是红、蓝两路灯不在同一瞬间关闭造成的过渡，不是红色故障。回退后再录 30 秒，紫色已经消失，只剩基础蓝色、读写青闪，以及新短信未读产生的短信组。“升级时约 6 秒紫色慢脉冲”和“失败退出后清理”这两点在实物记录中都看到了。“已验证候选 200 毫秒/10 秒紫闪”这次没有出现，因为暂存和试运行在同一个停机窗口里连续完成，没有“已暂存、还没试运行”的阶段。所以 LED-06 暂不记为完成。

## 过程中的小问题

试运行核对脚本前两次失败，原因是：暂存步骤已经撤销了保护定时器，核对脚本又去撤销一次，于是报“未加载”。两份失败记录已保留，改成“已撤销就跳过”后通过。这两次失败都不涉及服务的停止或启动。

全程没有拨打电话、没有从设备发送短信或推送、没有开启蜂窝数据，也没有重启设备或写分区。私有记录：`.private/app56-*`、`upd04-inject-20261028-first.json`、`upd04-after-20261028-first.json`、`inbox-count-*`。
