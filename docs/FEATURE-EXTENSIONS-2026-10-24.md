## X1：短信转发（必须真正停止进程）

参考：[pppscn/SmsForwarder](https://github.com/pppscn/SmsForwarder)。其主体是Android应用，不能直接把APK当成棒子的Linux原生功能；复用功能设计、规则语义及适合移植的实现，在Rust里接现有Core事件流。

- [ ] 默认关闭的持久总开关 `forwarding.enabled`，网页显示“已关闭 / 运行中 / 停止中 / 停止失败”。仅所有者最近登录可修改目标与总开关，密钥不回显。
- [ ] 独立 `rustsimhub-forwarder.service`（名称暂定），独立低权限用户和资源上限，不把循环嵌入Core/Edge。Core只保留有限事件/配置接口，不启动转发线程。
- [ ] **关闭：先落盘禁用和递增配置代次，再撤销任务租约、停止/禁用服务及其timer/socket/path触发源，等待所有子进程退出。确认无PID后才显示“已关闭”；退出失败明确报错，不能假报成功。**
- [ ] **关闭后的冷启动也没有转发PID、轮询、定时器、监听socket或网络重试。** 现有短信接收、电话、网页和普通NKN接入不随之停止。
- [ ] 禁用与并发新短信/迟到HTTP响应竞态：旧代次不能发起新递送；已经发出的第三方请求无法保证撤回，结果保留为不确定，不自动重发。
- [ ] Core已确认的新短信事件 → 持久有界outbox → 规则匹配 → 指定发送器。基于消息ID、目标、规则代次去重；跨重启保留游标/回执，不把SIM切换后的疑似重复记录自动当成新通知。
- [ ] 关闭期间暂停游标而不后台扫描。重新开启默认只处理之后的新消息；补发关闭期间/历史消息需用户明确选择并显示数量、目标和范围。
- [ ] 第一批：Webhook、Bark、Telegram、邮件；随后钉钉、企业微信、飞书、Server酱、PushPlus等按使用需求逐项适配。短信再次转发到手机号单独开关与预算，接现有唯一SMS提交/Unknown防重，不默认启用，防止转发环路。
- [ ] 规则支持发送方、正文包含/正则、SIM线路、时间段和目标组；限制输入长度、正则开销、队列/并发/重试次数；目标和凭据由所有者配置，测试消息显式标注。
- [ ] 各目标展示排队/递送确认/失败/不确定。第三方不支持幂等时不承诺恰好一次，超时与失去确认不盲目重投。
- [ ] 一键“测试转发”只使用合成文本；实短信转发按已配置规则执行。默认不外发验证码/完整正文，用户可明确选择转发内容和脱敏方式。
- [ ] 验收：关闭/重启无进程和网络请求；启用唯一进程；反复开关、网络断开、队列满、撤权、设备重启、SIM切换候选、第三方超时均不误发/循环；停止不影响电话和短信收取。

接口拟定（尚未存在）：`forwarding_status`、`set_forwarding_enabled`、`forwarding_rules_*`、`forwarding_test`、`forwarding_receipts`；Core负责鉴权/代次/状态，Root小助手只按固定服务名启动/停止，不提供任意命令接口。须在wire/IPC实现后才宣称可调用。

来源注意：已读仓库LICENSE（BSD-2-Clause），README另有非商业说明。先记录来源、固定实际复用提交并核对文件/依赖声明；首版独立Rust实现所需功能，不能仅凭GitHub标签宣称所有代码可无条件复制。短信转发器的Android通知监控、手机电量和手机通讯录不属于棒子首版；棒子已有的短信/通话事件可单独适配。

## X2：NKNGuard原生接入

已确认用户仓库：[Viper-Boss/nknguard](https://github.com/Viper-Boss/nknguard)。本次核对固定提交 **c32952d7586676fec10f71a30b22969cb24881f3**，README介绍NKN信令、ICE直连、WireGuard数据面、NKN中继、成员授权及私有DHT；LICENSE为AGPL-3.0。阅读源码不是在棒子上编译或验收。

- [ ] 原生Linux ARM64可执行程序/系统服务，独立启停和状态；无需NAS或Android运行环境。
- [ ] 快速路径先评估固定版本Go连接引擎与Rust有限适配器；若采用Go，明确标记为Go依赖，不能称其已被Rust重写。后续按协议与测试向量评估Rust移植，不重写成熟密码原语。
- [ ] 核对ARM内核WireGuard、TUN、工具及受限用户空间路径；先离线构建/隔离网络测试，再授权实机。Root权限仅留给固定TUN/路由/过滤助手，NKN信令和普通Core不拿任意NET_ADMIN。
- [ ] 复用配对、成员证明、签名记录、撤销和有限重连；RustSimHub Owner权限始终由Core验证。建隧道不等于已授予读短信/打电话权限。
- [ ] 只路由到本棒子明确授权的虚拟地址/服务，默认不改系统默认路由、不做NAS/局域网出口或客户端之间转发；不因链路失败开启普通蜂窝APN。
- [ ] 直连/NKN中继/DHT状态、延迟、收发量和错误可读展示；不拿本地邻居数冒充全网在线人数。
- [ ] 远程网页/API、远程语音分别验收。当前媒体有局域网/身份门禁，必须按真实远程通道增加明确授权及绑定，不能简单取消原限制。
- [ ] 在MSM8916测CPU/内存、长连接、传声延迟、断线恢复与电话并发；限制队列、并发和退避，不能挤占电话/短信服务。
- [ ] 暂不引入第二套无签名更新器、第二套Owner数据库或Web管理后门；纳入现有签名应用交付与回退。
- [ ] 一键连接测试给出“直连 / 中继 / 不可达”的真实结论；外网真实互通需对端配合，不能用本机loopback代替。

源码入口：`internal/app/backends_nkn.go`、`internal/app/backends_dht.go`、`pkg/signaling/nknsignal/`、`pkg/discovery/dht/`、`pkg/membership/`、`pkg/wireguard/`、`pkg/wireguard/userspace/`。第三方NKN SDK/NCP保留各自许可证及补丁出处。

## X3：NKN使用设备统计

用户明确指出已有源码；已定位并读取：

- [统计说明](https://github.com/Viper-Boss/nknguard/blob/c32952d7586676fec10f71a30b22969cb24881f3/docs/USAGE_STATS.md)
- [Reporter/窗口/派生密钥](https://github.com/Viper-Boss/nknguard/blob/c32952d7586676fec10f71a30b22969cb24881f3/pkg/usagestats/usagestats.go)
- [链上订阅与确认](https://github.com/Viper-Boss/nknguard/blob/c32952d7586676fec10f71a30b22969cb24881f3/pkg/usagestats/chain_nkn.go)
- [应用装配](https://github.com/Viper-Boss/nknguard/blob/c32952d7586676fec10f71a30b22969cb24881f3/internal/app/usage.go)
- 回归来源：`pkg/usagestats/usagestats_test.go`；本轮未运行该仓库测试。

原理是不同公开NKN主题的订阅数量：三个窗口对应24小时、30天、90天，定期零手续费订阅，链上确认后才记签到成功，重启保留状态；JSON-RPC无需保持NKN信令会话。参考时长8640/133920/393120区块，每日续订，按目标20秒区块增加一日余量；移植时再核对网络实际协议参数。

- [ ] 独立产品主题拟定 `rustsimhub.usage.24h` / `.30d` / `.90d`，不得混用nknguard/NasSimHub主题，否则软件用户数串在一起。
- [ ] 独立统计密钥与域分离，不公开/导出Core Owner、SIM身份或通信主密钥；同一统计公钥仍可跨窗口/时间关联，因此说明为假名化安装统计，不承诺绝对匿名。
- [ ] UI准确标成“近期活跃安装/设备估计数”，不是自然人数、全网在线人数或累计用户。公共主题可被第三方订阅，不能据此发奖励或授权。
- [ ] 不上传短信、号码、联系人、IMEI/IMSI/ICCID、通话、网络名或逐用户流量；明确公开的是统计公钥/主题/时间，RPC节点仍可能看到出口IP。
- [ ] 签到、读人数与设备联网分别处理。离线/错误显示未知及最近成功时间，不显示为零；有界超时、缓存、退避和重启防重复。
- [ ] 移植使用RustSimHub独立策略，不直接套用NKNGuard应用的 `AlwaysEnabled=true`。拟默认关闭，所有者首次开启时说明公开字段；正式启用策略待实现前确定，不在本轮自动参与或提交链上交易。
- [ ] 统计关闭停止报告任务及自动人数查询；没有其他使用者时不为统计维持NKN进程。历史链上订阅到期前可能仍被计入，不能承诺立即删除链上历史。
- [ ] 与X1转发开关解耦：关转发不能顺手关闭正在使用的远程连接；开远程连接也不自动开短信转发/使用统计。三个功能状态分别呈现。
- [ ] 验收：产品主题隔离、密钥域隔离、重启防重、确认失败/超时/时间回拨、错误不归零、停用无新签到、当前无流量卡不触发普通数据。
