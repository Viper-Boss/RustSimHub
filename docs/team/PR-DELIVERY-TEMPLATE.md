# 离线开发交付模板

复制到PR正文，删除示例但保留实际证据。单个PR只交付一个可评审工作包。

- 成员/任务：
- 起始main完整SHA：
- PR当前完整40位HEAD：
- 分支/PR链接：
- 对应台账动作及本PR的离线子范围：
- 具体问题和修改后行为：
- 改动文件、接口和依赖：
- 测试命令、真实退出码和结果：
- 未运行检查/失败记录/尚需设备验收：
- 实际有效工时（可不填；填写则标为成员自报，不估造）：
- 借鉴源码、固定版本、许可证与保留的来源：
- AI辅助工具及本人检查范围：
- 给主线Codex的集成步骤、风险、回退办法：

## 声明

本PR没有访问生产设备、使用真实通信数据或发起外部消息/链上交易；如事实不同，请明确列出已获授权的范围及证据。没有改写他人Git作者或虚报测试。确认本PR所列来源和依赖说明与提交内容一致。

## 由审核者填写

- 被审核完整HEAD：
- 结论：待审核 / 需修改 / 离线范围通过 / 已合并待实机 / 全范围验收。
- 验收动作与证据（逐项）：
- 未通过或排除范围：
- 对应合并提交/PR：

PR追加提交后，原结论只适用于原HEAD；不得沿用旧通过标记。
