## 当前事实与范围

已有 `rustsimhub-compat`，包含旧签名字节/版本、独立NAS会话和只读历史。`tools/nas-adapter/main.go` 是最小Go桥客户端；RustSimHub实际数据契约为 `adapter_api=1 / data_format=2`。旧NAS配对、控制、更新和PCM不能因HTTP可达就宣称支持。保留Go桥的真实语言与来源。

第一批对应NAS-01；第二批对应NAS-05、NAS-06的离线范围。NAS-02～04、NAS-07～08的真实页面、控制、声音、撤销/重启与完整端到端验收留给主线。

## 第一批：明确契约与只读桥（C-01～C-04）

### C-01 / NAS-01：盘点实际支持

1. 阅读 `docs/nas-online-bridge.md`、compat的lib/session/history/migrate、legacy黄金向量，以及Go桥入口。
2. 建一张逐路径/动作矩阵：支持、需要NAS适配、不支持、尚未实机验证，分别列状态/短信列表/详情/通话/控制/媒体。
3. 逐字段写来源、类型、缺值、稳定ID、线路代次及分页游标；不把旧“设备离线”直接解释成SIM无法注册。
4. 没有固定旧NAS源码时明确缺口，不猜字段；先以现有正式读取契约交付，旧页面集成由主线提供固定版本后继续。

### C-02 / NAS-01：状态和错误模型

1. 为正常、SIM缺失/锁定、观察中、后端不可用、兼容未开、版本不支持分别建有限模型。
2. 区分网络/HTTP错误、401/403、501未实现和业务暂不可用；不能全部转换为“离线”或空列表。
3. 只读返回不包含种子、兼容token、原始SIM/硬件标识；未知字段不猜造号码/时间。
4. 错误和设备字符串作为文本/强类型数据处理，拒绝超大输入、错误类型和不明版本。

### C-03 / NAS-01：实际只读转换组件

1. 在既有Go桥或compat中实现有限只读转换，明确输入/输出类型和允许的四类读取。
2. 列表/详情保留同一记录ID和线路代次；分页失败不推进已确认游标，重复页不重复副作用。
3. 复用现有TLS/设备pin/会话校验，不关闭证书校验，不跟随重定向，不把网络错误改成自动重试。
4. 不将读取token升级成v2/Owner/写权限；不启动旧硬件控制器，不新增拨号或短信发送路径。

### C-04 / 第一批交付

1. 使用真实模块与本地合成响应，覆盖成功/未知/缺值、401/403/501、错误JSON、分页/详情对应和超限。
2. 运行compat测试及必要的Go测试，给出实际命令/退出码；可执行的CLI也用临时合成配置验证，不接真实NAS。
3. 报告支持矩阵、字段映射、完整HEAD、来源/许可和旧页面缺口；等待主线确认契约，不调整全局进度。

## 第二批：历史差异与幂等（C-05～C-08）

### C-05 / NAS-05：导入前差异报告

1. 复用已有历史读取/迁移实现，先产出只读预检报告：来源格式/版本、记录类型/数量、缺失字段、冲突和拒绝原因。
2. 只接合成旧短信/通话/联系人；未实现的记录类型标不支持，不能默默丢弃后声称完整迁移。
3. 历史视图与当前SIM/当前记录隔离，保留来源和未知值；不得覆盖设备身份、Owner、当前线路或发送操作。
4. 报告默认不包含正文/号码等内容；逐条调试只在合成夹具中展开。

### C-06 / NAS-06：重复、部分导入及恢复

1. 相同包重复导入幂等；相同旧ID但不同来源/内容不能盲目覆盖。
2. 以真实临时数据库/文件后端测试中断、写入失败和恢复后重跑；不使用只在测试里存在的替代实现。
3. realm/SIM代次改变、旧游标/映射重用不能使历史变成当前记录。
4. 历史操作永远不能恢复为待发送短信/待执行通话，导入不能触发任何硬件副作用。

### C-07 / NAS-05/06：权限和输入矩阵

1. 覆盖拒绝越权历史读取、撤销/错误NAS身份、过期/错误版本与非法路径输入；不改变现有授权器语义。
2. 覆盖大小限制、恶意名称、无效UTF-8/二进制边界、缺字段、时间缺失及重复记录。
3. 验证失败保留原历史和当前库，不通过删除来源/清空库解决重复问题。

### C-08 / 第二批交付

1. `cargo test -p rustsimhub-compat --locked`、该包严格Clippy、fmt及对应Go测试；真实命令以仓库当前模块布局为准。
2. 给出导入前后差异、重复运行次数/结果、原数据保持证据及未运行项。
3. 写主线集成说明和真实NAS补验清单；不将离线模型/回环测试写成真实NAS页面或双向声音验收。

本成员不负责新版手机App，不接管NKN统计、月流量或短信核心状态机。需要跨模块变更时独立提出，交主线协调。
