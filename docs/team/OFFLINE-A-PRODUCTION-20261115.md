## 4. 两包共用的接口与交付契约（本节冻结）

### 4.1 保留现有统计接口

`crates/usage-stats/src/check_in.rs`的`CheckInTransport`保持以下语义：

| 方法 | 必须满足 |
|---|---|
| `acquire_statistics(lease,budget)` | 只取得本次统计引用；部分取得失败也能释放；不能创建另一个无Owner授权的后台引擎 |
| `release_statistics(lease)` | 只释放统计引用；Remote/Manual仍使用引擎时不能停它们 |
| `prepare(lease,intent,budget)` | 纯本地构造/签名，返回**真实交易摘要**；不能发网络提交，不能以意图JSON哈希冒充交易哈希 |
| `submit(lease,intent,digest,budget)` | 仅提交已准备的原交易一次；返回成功也不等于链上确认，所有不明结果保留原摘要 |
| `query(lease,intent,digest,budget)` | 只核对原意图和原摘要，返回现有严格`{intent,digest,status}`；身份、主题、窗口和链上证据均要核实 |

- 继续使用库的单一总预算、取消代次和持久Pending语义。先落盘摘要再允许submit；重启只查原交易，不自动重新准备/重发。
- 24h/30d/90d主题、独立身份域分离及查询协议沿用`docs/usage-stats/`和现有库。不混用NKNGuard/NasSimHub主题、Owner/SIM/通信种子。
- 先核固定上游：`docs/nkn/fixed-upstream.json`、`tools/nkn-build/sdk-evaluation/source-manifest.json`、已有patch manifest与许可证。`SubscribeContext`最终会调用发送，不能作为纯prepare。
- 生产提供者仍需显式feature/启动模式。原本地Owner最长300秒Root权限不延长、不自动续权。长期运行先交明确方案及默认不可启用的候选/拒绝路径；不能用`AlwaysEnabled`、替代Owner、延长媒体租约或删检查来“打通”。
- 若需新增可信Root操作，先在A的第一个接口PR定义有限请求/响应、版本协商、预算、来源和拒绝分支；不能透传任意URL、RPC method、shell、UID、目标路径或签名消息。Root策略默认拒绝新增能力。B只消费此契约验证/打包，不替A改业务协议。
- 支持不足返回明确unavailable/unknown，不能将`reporting_available`改成true而没有真实接线。既有`usage_participation_*`仅保存许可，不能把该文件自动升级为永久Root capability。
