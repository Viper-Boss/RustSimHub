# 灯控直接读取系统缓存状态（主线C3a）

2026-11-02。用户已授权持续主线开发和设备调试、人工验收最后；本页记录负责人选择的实现边界，不增加一次例行确认。灯控生产代码归主线，D继续原测试包，network-agent生产优化保持B的原分工。

71版两分钟只读观测：灯控cgroup约4.723%单核，其中已回收子进程4.108%、自身0.608%，子进程占87.1%；network-agent约16.525%、子进程15.8%，进程写入77,824字节且meter文件mtime改变。窗口eMMC主机写入2,174,976字节；这不是24小时/压力或功耗验收，不能直接换算实际日磨损。原始记录仅在私有目录。

采用每15秒直接读取系统总线快照，替换灯控启动systemctl/nmcli的路径。只用既有锁定的tokio1.53.2和zbus5.19.0；Cargo.lock仅给本包增加两个现存依赖引用，没有新增包/升级版本，不增加Root能力或地址族。C2的network-agent连通性字段扩展仍由B按原分工决定，本包不接管。

固定十个systemd单元，GetUnit/ActiveState；对未加载但已存在的文件仅GetUnitFileState，不Load/Start/Reset。NM最多16个唯一设备路径，只读取设备类型、激活状态及已有每设备IPv4/IPv6连通性缓存；不读全局连通性作为Wi-Fi证明，不主动探测/扫描、不启APN/切路由、不取凭据。只接受本次前后相同的PID1/NM唯一owner；未知/坏类型/外来路径/超时拒绝，下一采样按既有红灯规则处理。整次观测3秒截止，采样仍15秒、动画20ms/业务提示200ms不变。

原灯控只读取wlan0连通性，单独蜂窝即使已有full缓存也无法读取该事实。本次对已激活蜂窝也只读取其已有缓存；unknown/none仍保守显示未确认互联网，不设置蜂窝探测。颜色策略本身保持；蜂窝单链路的实际灯效/计费仍待换卡真人验收。

新增本机--probe-readonly只返回服务/网络布尔快照，不写GPIO；明确不包含Core业务提示/完整动画状态。不新增网页按钮或远程控制入口。先以实际受限单元验证探针，再备份/回读/单独更新灯控，复核原应用71和网络计量保持并重复同窗口采样。目标灯控单核低于2%，以实际测量为准，不先报性能成功。
