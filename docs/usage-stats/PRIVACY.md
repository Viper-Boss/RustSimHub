# 统计同意与隐私契约

统计功能默认关闭，与 NKN 远程访问、短信转发、VPN 和普通蜂窝数据分别控制。本批只是离线 Rust 库；没有设备、NAS、NKN/RPC、Bark、运营商或生产服务访问，没有自动联网和链上交易。

## 所有者看到的披露

开启前须明确告知：统计会使用独立的统计公钥，参与 RustSimHub 三个公开产品主题，形成近期活跃安装的参考计数。公钥、主题、必要窗口/续订信息和真实提交后可观察的时间属于公开信息；同一统计公钥在不同窗口和不同时间的记录能够相互关联。NKN 节点还可能观察请求来源 IP 和时间。统计是假名化，不是不可关联或完全匿名。

`OwnerConsent::Granted` 与 `DisclosureAcknowledgement::Current` 同时具备才可取得开启策略；拒绝、配置缺失或未确认当前披露都不能产生签到意图。库接收显式同意输入，不负责识别真实 Owner 或提供管理页面；主线后续通过已审核的鉴权入口取得这一输入。不能用 `AlwaysEnabled`、旧默认值或 NKN 远程访问开关替代统计授权。

## 独立身份与公开 DTO

`StatisticsIdentity::generate()` 从系统随机源取得独立 32 字节材料；随机源失败返回 `EntropyUnavailable`。`from_seed([u8; 32])` 允许恢复/测试时注入专用统计材料，不能读取或派生自 Owner、SIM、短信、通信 NKN 主身份或设备主密钥。库不能识别调用方是否故意传入其他业务种子，主线必须保证输入来源隔离。

固定域分离标识 `IDENTITY_DOMAIN = "RustSimHub/usage-stats/ed25519-seed/v1"`；对标识字节、NUL 分隔字节及专用种子使用 SHA-256，再由 `ed25519-dalek` 生成 Ed25519 公钥。使用既有标准密码库，不实现自创曲线算法。保存格式同时绑定该产品/用途域与统计公钥；其他产品/身份的记录不能直接采纳。

公开 DTO 只允许统计公钥、RustSimHub 产品主题和必要协议版本、窗口、区块周期/续订周期等字段。不得包含手机号、短信/联系人、IMEI、IMSI、ICCID、SSID、个人流量、设备主身份、种子或任意外部密钥路径。字段严格解析，不接纳“额外字段以后忽略”的扩展。

统计种子是本地秘密，不能作为公开 DTO 导出；身份对象没有公开种子导出或 `Serialize`，`Debug` 只显示公钥和种子已遮蔽标记。公共状态、序列化输出和错误消息不得泄漏种子。实现使用 `zeroize` 包装持有的种子及私有读写缓冲；`from_seed` 调用方仍负责清理其自行持有的副本，不能将这一机制宣称为整个进程所有副本的绝对清除证明。

显式 `FileStore` 后端在受限本地文件内保存重开所需的身份材料，持久文件因此不是可公开日志，也不是加密保险箱。Linux 目录 0700/文件 0600 等检查的边界见 [STATE-MACHINE.md](STATE-MACHINE.md)；Windows 只继承调用方 ACL，生产私有存储安全仍待验收。调用者不得把文件内容、原始错误输入或种子上传进交付证据。首批测试只使用临时目录与合成材料。

## 计数与关闭语义

公开主题允许第三方订阅；重装或更换统计身份可能产生多个安装记录，同一自然人可能使用多个安装。计数不等同于自然人数，不能证明设备健康、精确使用时长或唯一真实用户。区块间隔并非固定 20 秒，24 小时/30 天/90 天是目标窗口标签，不是精确墙钟覆盖保证。

失败查询显示“未知”或带原成功时间的“旧缓存”；只有成功响应能显示 0。时间回拨不能将旧缓存重新标成新鲜。关闭时不创建密钥、任务、队列或网络调用；独立统计开关不改变短信转发、VPN 或蜂窝数据状态。后续真实订阅一旦公开，关闭本地功能不等于删除公开历史，订阅也可能直到链上实际到期前仍存在。

## 第一批实际边界

本批提供默认 OFF 策略、纯签到意图 DTO、独立身份/持久格式和可注入的只读查询组件。尚未实现真实 SDK/IPC、提交和确认状态机、提交中禁用/迟到回复隔离、真实 Owner 页面、服务资源释放或设备进程验收。没有这些实现时返回明确不可用/缺口；不能把合成 transport 的成功称为真实网络或链上成功。
