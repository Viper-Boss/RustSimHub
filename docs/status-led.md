# UFI003 指示灯约定

用户于2026-10-21确认以下规则。实现/实机验收以HANDOFF顶部为准；本表不是已全部验收的声明。

| 情况 | 指示 |
|---|---|
| 系统关键服务故障 | 红色常亮 |
| 蜂窝数据已连接，且有可用互联网；可同时有Wi-Fi | 绿色常亮 |
| 只有Wi-Fi，且可访问互联网 | 蓝色常亮 |
| 无Wi-Fi/蜂窝连接，或连接后不能访问互联网 | 黄色常亮 |
| eMMC发生读写 | 青色120毫秒，最多每5秒一次，随后恢复原色 |
| USB配置、首次配置或已授权网页配置会话 | 白色慢节奏，约6秒一轮 |
| 已验证的新固件可更新 | 紫色200毫秒，每10秒一次，随后恢复联网原色 |
| 固件升级中 | 紫色慢节奏，约6秒一轮 |
| 未读短信 | 蓝→青→绿，每色280毫秒、间隔20毫秒，共0.9秒 |
| 未接来电未确认 | 红→黄→紫，同上，共0.9秒 |
| 两类未读同时存在 | 蓝→青→绿→红→黄→紫，共1.8秒 |

未读动画最多每30秒一组，查看/确认后停止对应提醒；高优先级状态期间不播。优先级：关闭配置→故障→升级→配置→未读提醒→新固件提醒→读写→联网原色。这里“关闭配置”指用户显式关闭指示灯，不是退出网页配置。退出网页配置必须恢复下层状态。

USB只是接入方式；连接NAS本身不代表仍在配置。首次尚未完成配置时显示白色；USB初始化进行中也显示白色。网页配置用经过权限检查的短租约，关闭/保存退出释放，异常断开最长30秒恢复；浏览未授权页面不能改变灯。

本板三个通道为gpio-leds，max_brightness均为1。红绿合黄、绿蓝合青、红蓝合紫、三色合白；须实物确认混色。该接口只支持开关，当前实现的“呼吸”是慢明暗脉冲，不能宣称连续亮度渐变；不在弱CPU上高频写sysfs模拟PWM。

灯控程序只写三个固定LED sysfs路径，空capability，不能控制任意GPIO、网络配置或短信/通话。Core输入仅包含30秒内租约及两个未读布尔值，不传消息内容、号码或身份。升级输入只能由Root更新执行器发布，不能以GitHub存在新提交冒充已验证升级。

联网判断使用NetworkManager的每设备缓存连通性。主动探测只允许wlan0，使用Debian的连接检查端点，每120秒、4秒超时；其余接口明确关闭探测，尤其不能对WWAN启用普通APN或探测流量。全局状态不等于本设备的Wi-Fi状态。参考[NetworkManager配置文档](https://www.networkmanager.dev/docs/api/latest/NetworkManager.conf.html)的device.check-connectivity和connectivity节。探测端点不可用/门户也会显示黄色，不能把此灯当成完整互联网可达性保证。

## 接线与验收边界

当前灯控源码包含完整策略和固定设备输出、Core配置租约、网页保存/退出/关闭提示，以及未读/升级事件接线。网页提示需要network.manage权限；仅status.read的客户端不能改变配置指示。每个页面独立view_id，客户端串行发送结束动作，服务端25秒到期；Root读到的Core输入还必须在10秒内保持新鲜，且只能由UID986的私有目录/单链接0600普通文件提供。

未读是设备级提示，不继承NAS旧用户的历史标记。Core仅从当前line_epoch的业务库做只读投影，换SIM后未重新观察的通话不能触发提醒；接通过的呼叫不会误作未接。读取详情不自动确认，网页成功展示后另发notification_read；需要对应sms.read/calls.read并验证记录存在，标记持久保存成功才返回成功。UI标记单独保存为Core私有state/indicator-read.json，数据库schema仍为5，保持旧应用回退兼容；单独SQLite备份不包含这个可重建的提示元数据。首次接入时将已有记录作为基线，避免历史记录集中闪灯。

未读输入不包含号码、正文、消息ID或SIM标识。只在业务事件版本改变时重新拉取有界记录投影；持久读标记仅在变化时写入，输入提示落在/run，不制造eMMC读写提示循环。网络/服务采样在独立线程，不能拖慢0.9/1.8秒动画。配置、升级等高优先级状态阻止未读动画；退出后仍有未读会继续每30秒提醒。

新版本提示读取固定Root更新存储中已经过签名/载荷验证的candidate记录，要求比confirmed版本新且不超过floor；未尝试为紫色短闪，正在试运行且尚未确认则为紫色慢脉冲。Root更新程序stage/choose期间另发布有界活跃提示，退出/失败清除，异常死亡最多10秒过期。没有自动更新源检测，不把GitHub新提交当作可安装固件。

实机已安装独立灯控，服务启用、空capability、三个固定sysfs写入范围、白色配置脉冲读回均通过，用户确认“白色慢速亮灭正常”。业务程序仍未初始化，网页/真实未读/升级/蜂窝的联动必须在新业务制品交付并启用后做实机验收；不能用策略或IPC测试替代该结论。最终运行版本及制品入口见HANDOFF。
