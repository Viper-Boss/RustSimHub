# X1I：一键合成转发测试

2026-10-25。当前为源码候选，最终验证结果见下文；没有部署棒子或联系真实推送平台。原 P0–P7 仍 80%，新增扩展单列。

## 用户操作和实际路径

在折叠的“短信转发”区保存目标、明确开启转发，读取到真实运行证明后，选择一个已保存目标，点击“发送一条合成测试”并确认。目标仍支持 Webhook、Bark、Telegram。测试使用固定的“RustSimHub 合成测试”内容，不接收客户端提供的正文、号码、地址或密钥，不插入业务收件箱，也不移动短信事件游标。

测试复用实际 Core 队列、独立低权限 worker、固定网络出口、HTTPS 和三阶段鉴权检查。不开第二条临时发送通道，不通过短信运营商发送。测试本身不修改开关；已经开启的真实转发规则继续处理新短信。关闭状态不能测试，也不会为测试偷偷开启进程。

新增所有者命令 `forwarding_test` 接收当前配置代次、请求 UUID 和目标 UUID；要求最近登录所有者、当前持久身份/realm、已启用策略及 Ready SIM。尚无 Ready SIM 的离线推送测试本轮不支持。普通配对客户端即使有 system.manage 也拒绝。接受入队不等于目标确认递送。

新 `forwarding_test_request` 是所有者只读查询，精确返回该请求的合成任务回执。查不到保留“不是未执行证明”的含义，不触发外发。回执仅含 ID、代次、状态和 `synthetic` 类型标记，不含正文或凭据。Webhook 负载明确为 `event:forwarding_test` / `test:true`；Bark 标题、Telegram 文本均明确是合成测试，沿用各平台原应答核验。

## 防重和有界观察

浏览器沿用跨页原子预留的最小回执，新增 test 种类和所选目标 ID。先持久化，再提交一次；不与电话/SMS 待处理操作混用。保存失败不提交，失去提交回复只保留记录。一次测试最多发起 10 次间隔约 1 秒的只读查询，并在 15 秒观察预算到期后停止发起后续查询；在途请求仍受原有 RPC 截止控制，所以这不是严格的 15 秒总耗时承诺。

confirmed、failed、cancelled 可按精确回执归档；unknown、未找到、超时保留，不自动重发。退出、页面隐藏、折叠配置区使旧观察失效，不再发后续查询；这不撤回已接受的任务。之后可显式核对或保留不确定记录后继续。

同一个请求 UUID、目标和配置代次返回同一任务，不能造成第二次 provider 写入。每代至多 64 个测试记录，同时遵守原有 256 未决/4096 回执总上限。当前代的测试记录即使已完成，也不随终态清理删除，避免清理后重放；配置代次变化后才允许清理旧终态。旧代请求不能重新提交，Unknown 在任何代仍保留。Core 为合成消息另生成 UUID，客户端不能指定业务消息身份。

## 独立 outbox 格式升级

业务库仍为 schema6、worker 协议仍为4。独立 outbox 从 format1 升至 format2，增加 jobs.purpose 类型列。新库在同一初始化事务中建立新列和版本；旧库先核对 Owner/realm 和完整性，再事务添加默认 sms 列并升级版本。原配置、游标、任务请求和 Unknown 保留，开机中断任务仍恢复为 Unknown。

format1 的旧 Core 不支持 format2。尚未部署此变更；后续签名安装必须连同一致性 outbox 备份和兼容回退处理，不能只替换应用再假定旧 Core 可读取新库。

## 验证

最终本机验证通过：433 项 workspace Rust（本轮新增6项）、严格 Clippy、生产 feature 检查、14组实际网页源码夹具，以及四份生产 ARM64 的 ELF/摘要和 Core/worker QEMU 元数据。

真实 systemd 普通路径保持原两条合成通知；管理路径经实际 Owner→Core→队列→独立 worker→DNS/TLS 共三次 HTTP，其中两次为原兼容夹具通知，一次为本轮固定合成测试。测试确认后再次发送同一 API 请求，精确返回 confirmed，HTTPS 计数仍为3；接收端还核对固定合成负载字段与文本。实际整组停止、条件开机跳过、凭据及临时授权清理通过。原四UID IPC和四组真实 worker DNS/TLS/停止兼容路径通过。

私有入口：`.private/forwarding-synthetic-checkpoint-20261025-first.json`。最终完整回归为 `forwarding-synthetic-check-20261025-seventh.log`，网页 second，真实服务、兼容和 ARM 为 first。前六轮编译/测试/lint失败日志均保留：计数解码类型、测试UUID依赖和有效LineStatus构造、两处字段名误判及测试锁守卫生命周期；修正具体问题后完整重跑，没有关闭 lint 或放松权限。最终精确提交的公开 CI 另存，不预先算通过。

新用例覆盖：只选一个保存目标、固定合成编码、同一请求重复受理、完成后清理/重开防重、每代容量、Unknown 保留、旧格式迁移和错误 Owner 拒绝迁移、未就绪 SIM 拒绝、实际 Core 查询、浏览器最小记录/有界只读观察/失去回复/存储失败/关闭配置区及真实 app IndexedDB 接线。

本轮不访问 NAS 或棒子，不拨号、不发送短信、不启用普通蜂窝数据。真实第三方目标、浏览器视觉、签名安装、棒子 OFF/冷启动/断网验收仍缺；完整 X1 未完成。
