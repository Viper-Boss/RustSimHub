# 不确定拨号的有界清理和手动归档

2026-10-23。正式系统首次语音试验暴露客户端清理缺口，已完成源码和离线修正；未部署，整体77.5%，不为代码修正重复计电话验收点。

一键流程现在先核对返回租约是否绑定本笔operation.call_id、当前SIM代次、有效boot/generation及最多30秒的有效期。即使拨号状态unknown，只要持有这笔匹配租约，仍可走一次挂断及有界只读确认；不会再次提交拨号，不会为不确定拨号启动PCM，不续租。清理前的挂断持久记录嵌入原不确定拨号记录，下一次明确测试前归档该收据。错误/缺失/过期或其他呼叫的租约不用于清理。

页面增加“归档已结束的不确定呼叫”，仅由用户手动点击。它查询原操作、当前活动呼叫数量及准确call_id详情；只有dial/hangup、unknown/submitting、无活动呼叫、准确ended/observed，或Core重启后标为reconciling但持久的最后观测modem_state仍为终止值7时，才先持久保存收据再清除当前浏览器指针。设备原Unknown记录不变。不支持短信/DTMF，不把unknown改成submitted，不发送拨号、挂断或取消命令；归档后任何新测试仍需用户再次点击。
