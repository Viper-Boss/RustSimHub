# 固定候选的首次整机启动实验

2026-10-21，用户明确要求“不用刷回旧系统，你直接测试新系统”，并授权“你想怎么测试怎么测试，目标是先把系统做出来”。据此调整执行顺序：不再要求先完成旧系统实际回刷演练，直接准备并验证新OS实机安装。已完成的只读9008返回、完整干净备份及16KB硬件能力证据继续使用；**实际回刷能力尚未验证**，不把用户改变顺序记为技术验收通过。普通蜂窝仍等换卡，不写GPT、boot、基带/NV/校准分区。

`tools/recovery/install-system.py`是Root本地有限入口。prepare只接受P6N固定已审计通用rootfs的准确摘要、P6Q所选维护资料的匹配状态副本，以及独立干净的原始备份/计划。它从只读固定FD复制完整主区到新普通文件，仅覆盖副本p14、p15，核对所有保护字节及GPT/boot保持，执行独立整图和两个只读文件系统检查，重新核对源图与两输入未变后才写安装计划。副本含设备私有资料，不进入Git或发布包。

安装计划明确标记fixed-system-install-plan、experimental_cold_boot_only=true、restore_rehearsal_verified=false；所有发布/恢复/启动验收门禁保持false。计划绑定安装器及全部共享执行源码、原备份证据、两个输入、完整候选和固定分区摘要。默认validate重新核对，不连接USB、不停机、不消费标记。

实际install必须选择准确计划摘要并显式接受未经完整回刷演练的实验顺序。共享有限写入状态机接受这类独立计划，但仍仅允许p14/p15、16KB固定配置、逐字节计数、明确开始/结束ACK、当前完整前快照、完整写后回读、两个文件系统检查和**执行前当前保护字节**保持。使用独立install-attempts单次标记；原失败restore-attempts及NAK报告保留。短写、NAK、未知结果立即停止，不自动重试/reset。

写后校验及reset ACK不代表新OS正常启动。须另行匹配物理USB口、所选串号和MAC，使用事先登记的NAS无默认路由USB配置，以本机原维护私钥和固定新主机公钥连接。首次实机验收先检查挂载、所选身份、USB、SSH和启动错误，再验证固件/无线驱动、调制解调器与业务初始化；业务认领及音频等后续验收独立记录。手机原生App不在本轮。

本检查点仅完成源码及122板级/34rootfs/7恢复隔离回归；NAS安装副本生成与默认验证、新系统实际写入及启动尚待实测。整体仍74/100，不为调整顺序或新增工具加分。
