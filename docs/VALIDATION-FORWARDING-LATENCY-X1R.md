## 验收改进

`tools/test-forwarding-worker-process.py` 的合成 TLS 服务器新增 0–2 秒响应延迟，仅测试使用。托管 Root 验收固定使用 1 秒，仍要求所有四个请求及准确回执，并保持原生产租约、Root 作业预算及测试等待上限。没有增加自动重试或放宽结果判断。

`tools/test-forwarding-supervisor.py` 保存最后一笔合成回执的存在性、状态、临时活动标志和自动停止确认；若失败，仅输出这几个状态标签及已观察到的合成 HTTP 数量。没有输出 Owner token、请求 ID、正文、目标或凭据。这样下一次失败能够区分未递送、仍在活动和关闭证明缺失，避免只有一个等待超时。
