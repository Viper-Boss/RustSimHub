# NAS只读管理的主线网页装配

本包装配已有Core/NAS读取能力，不实现旧NasSimHub完整页面、短信写入、电话控制或PCM。产品实现位于 `nas-bridge.js`，经显式 `/nas-bridge.js` 路由嵌入日常Edge；没有依赖、设备schema、身份协议或后台进程新增。现有首页测试按钮和默认折叠方式保持。

## 用户路径

1. 现存Owner最近5分钟内登录。NAS先使用独立公钥完成原v2配对申请与Owner核对批准；本区只列active、kind=nas、具备只读权限的记录，不提升普通客户端或Owner为NAS。
2. 展开“NAS只读接入（可选）”，点击“读取NAS与绑定”。页面读取已批准列表与当前别名；不绑定、不启动连接。
3. 核对完整NAS公钥和别名后，明确确认“保存只读绑定”；仅使用已获批的status.read/sms.read/calls.read交集。版本、公钥、授权代次及权限集中在可展开详情。
4. 撤销须先核对并明确确认，发送原绑定epoch。它不撤销NAS principal或其他客户端，只清理指定版本的读取映射。

绑定参数用于既有NAS客户端配置，不包含Owner/NAS/设备种子或登录令牌。此页没有自动生成完整NAS配置或导出私钥，也没有承诺所有者批准步骤已在真实设备完成。

## 跨页、跨设备与不确定结果

- 保存/撤销前，先将有限意图以IndexedDB事务CAS写入本机；持久化失败或其他页已占用时不发写请求。意图含本地跟踪UUID、动作、别名、NAS公钥/generation/只读权限、原epoch或明确缺失、实际已验证设备pin。此UUID不是Core服务器幂等键。
- `authenticatedDevicePin`来自已验证登录挑战的签名transcript，并且只在authenticate成功后生效；不从随时可改的表单值推断已认证设备。新登录、退出、pagehide与页面隐藏均清理旧视图；续期不刷新Owner最近登录权限。
- 待确认记录属于另一pin时阻止查询和清理，保留原记录供切回原设备核对；旧请求晚回复不覆盖新视图。切换选择/别名会使原快照失效，必须重新核对。
- 所有写操作只发送一次。超时、拒绝、错误回复、归档失败或退出后结果未确认时，保留原意图；只读查询不会重发、自动绑定、自动撤销或自动归档。
- 正常回复须精确核对alias/public_key/generation/scopes及新epoch后，才留存 `source:reply` 回执并CAS关闭原意图。
- “确认本次核对结果”只在原意图之后的一次查询可用。经用户明确确认，保存 `source:current_state` 和当前快照；它表示看到了当前状态，**不表示原写操作执行成功**。未决或冲突记录不能被其他页默默覆盖。
- 本机回执上限64，不自动淘汰未知记录。保存失败继续保留原意图。展开“本机回执留存”可准备并下载JSON，只包含当前已验证设备pin的回执及待确认意图，保留`reply`与`current_state`区别；不导出私钥、令牌或短信正文。公开设备/NAS标识仍应妥善保管。
- 导出不会自动清理。下载链接被点击后，所有者仍须明确确认文件已保存，才能清理本次导出且仍完全相同的回执；浏览器无法证明文件已保存。清理在同一IndexedDB读写事务中读取待确认意图和回执，仅写回回执键；保留待确认意图及关联回执、其他设备和其他页面新增记录。原回执已更改或被移除时整笔拒绝，不进行部分清理。
- 导出读取也是单一事务快照。退出、隐藏页面或切换已验证pin会让旧链接/清理上下文失效并撤销Blob URL；迟到读取不生成下载，迟到清理在写入前检查会话。导出/清理均不发Core请求、不重放原操作、不修改棒子。导出文件没有导入执行功能。

## 实际测试与边界

`tools/test-web-nas-bridge.mjs`调用真实生产模块，覆盖严格回复/意图校验、32位掩码溢出、有限只读权限、原子保存早于发送、确认取消、并发页CAS、映射版本冲突、回复丢失、错误回复、归档失败、跨pin、退出/迟到回复、重新读取与显式当前状态留存。其他六组装配夹具注入真实NAS模块以保持原电话/短信/会话行为；没有用假NAS控制器替代新增行为。

导出/清理测试额外覆盖严格白名单、64条上限、跨pin过滤、下载与明确确认门槛、原回执冲突、新增回执保留、待确认关联保护、事务提交/中止、存储配额失败和退出迟到回调。IndexedDB测试使用异步事务模型；真实浏览器下载及存储验收仍待最后进行。

真实UnixStream/Core/SQLite测试覆盖条件写入、旧版本拒绝、拒绝后的原ledger字节与有效会话保持、撤销、NAS/错误代次/写权限拒绝。全仓回归与ARM编译以固定提交验证记录为准。

本地可运行 `python tools/fixtures/nas-bridge/serve.py --report NEW_PRIVATE_REPORT`。服务器只绑定loopback、只提供五个允许的静态路径，无目录列表，CSP拒绝外部/业务连接；使用真实HTML片段、CSS与生产模块。合成数据/确认只存在fixture内存，不加入生产路由、查询参数、localStorage或隐藏开关。

本轮Chrome合成流程及1440/390/320的DOM布局检查已执行；后续原生截图捕获因浏览器网址无法可靠核对被工具停止，未继续UI输入。正式截图产物、用户视觉批准、真实Owner/NAS读取与撤销、设备部署仍未验收。开发验证不能代替这些结果；用户要求人工验收最后进行。
