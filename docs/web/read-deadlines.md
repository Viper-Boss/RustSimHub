# 成员B候选组件的绝对读取时限

恢复控制器的Core方法、诊断原ID查询和配置状态读取保持3秒预算；统计展示保持10秒。此处不修改T5 Core/NM试连40/45秒预算或真实服务权限。

计时器先于外部端口调用注册，回调仍先reject再Abort，避免Abort清理返回正常值抢赢超时。端口返回后另用performance.now单调经过时间核验：到达预算、时间倒退或非有限时，拒绝该结果并Abort。仅有Promise.race不能覆盖事件循环暂停后已经排队的正常回复，也不能把同步调用耗时排除在预算之外。

恢复写入失败仍是Unknown：保留原UUID和写前标记，只有原ID查询，不自动重试或声称设备已取消。只读展示保留未知/原回执，不把迟到的ready、submitted或running当新鲜证据。reset/旧epoch检查继续有效，没有自动网络轮询。

UI无法抢占同步JavaScript；若外部实现阻塞，只有其返回后才能拒绝迟到结果。生产端口仍须异步、有界并在Core自行检查权限、期限和回滚证明；本检查不是认证、设备取消或资源已清理的证明。

DiagnosticPanel与其他候选一样允许构造器注入测试clock，默认performance.now。该测试接缝不从URL/存储启用，不接受网络自报时钟，也不授予设备能力。

回归 `node tools/test-web-deadlines.mjs`：4项Abort竞态加12项未触发计时器时的到期/倒退/无效时钟，直接执行四个实际模块，断言一次调用/Abort、定时器清理、未确认显示和原标记保留。另用原生performance.now/计时器和3.05秒同步阻塞验证恢复结果拒绝；没有修改或放宽产品时限。
