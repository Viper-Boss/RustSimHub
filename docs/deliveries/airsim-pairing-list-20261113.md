# AirSIM 配对列表刷新修复 · 2026-11-13

用户最终澄清：iPhone 已显示配对成功，未显示设备的是网页。之前“手机超时”的判断撤回。设备只读证据有两条已保存记录及后续签名活动；它们不代表两部不同手机，也不能当成真实通话声音验收。

## 问题和实现

旧控制台开始配对后只倒计时，没有继续读取状态；手机在另一端完成配对后，网页仍保留空列表。读取失败的统一提示也把只读失败描述成“设置结果未知”，容易被理解成配对失败。

进入已登录的安全策略页，或开始配对/手动读取后，控制台短时自动读取 `airsim_status`：5秒最小间隔、最多30次、150秒上限、单请求在途；连续3次失败停止。隐藏页面暂停，离开安全页停止，退出清理，旧响应不能更新新会话或页面。没有自动开启、关闭、重新配对、保存音质或撤销配对。

新记录在下一次成功读取后显示，并清除已消耗的配对码。读取超时/拒绝/坏响应保留旧列表并明确提示“列表暂未更新，不会撤销手机配对”；不会用坏数据伪装成空列表或关闭状态。自动读取保留未保存的音质选择，条数按“配对记录”展示，不误称独立手机数量。手机协议、Core授权和配对密钥保持原样。
