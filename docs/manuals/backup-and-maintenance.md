# 备份、恢复与维护 · 草稿

[手册目录](README.md) · [支持范围与证据](support-evidence.md)

## 先分清备份对象

| 对象 | 为什么要保存 | 当前边界 |
|---|---|---|
| 设备身份 | 用于识别同一设备并匹配持久数据 | 加密身份恢复已有有限实测，不包含全部业务数据 |
| 所有者和浏览器恢复材料 | 证明原来的客户端身份与权限 | 不能从短信数据库重新生成丢失的客户端私钥；保管方式由负责人交付 |
| 短信、通话、操作和授权数据库 | 保留记录、操作状态及授权事实 | 使用真实一致性备份接口；不要复制在线 SQLite 主文件就当完整备份 |
| 转发 outbox、配置及其他独立数据 | 保留转发任务/回执、保存的设置和其他域 | 不能假定已经自动包含在主业务数据库或身份备份里 |
| TLS、媒体及部署配置 | 保持可信访问与运行环境 | 属于单独维护范围，不随身份密文自动恢复 |
| 系统与恢复材料 | 用于整机维护与恢复 | 不属于身份备份；本稿不提供整机恢复步骤 |

范围依据：[加密身份 S09](support-evidence.md#s09)、[业务一致性 S10](support-evidence.md#s10)。
仅拥有一个备份文件、能够解密或数据库完整性通过，都不能证明跨库数据来自同一时点。
具体哪些对象纳入本次备份，必须由负责人列清并验证可读取。

## 普通用户如何准备备份

向负责人说明要保留哪些内容、当前是否有活动通话或未知操作，以及哪些客户端需要保留身份。
由负责人选择与当前版本匹配的维护方案，并给出备份范围、生成时间、版本及核验结果。
身份、恢复钥匙和正文等材料只通过负责人指定的私有渠道保管，不能放到公开仓库、issue 或聊天截图中。
不要为了准备备份自行导出浏览器钥匙、读取设备私有目录或运行网上找到的恢复脚本。
[已有验证及未覆盖内容](support-evidence.md#s09)

## 恢复前必须由负责人确认

负责人需确认原设备身份、原所有者证明、业务数据以及各独立数据库/配置是否匹配，
备份能否读取，目标是否全新且正确，以及失败后的恢复入口。
活动库不能被旧备份覆盖；不能让两份恢复库同时控制一台设备。

现有 Store 恢复会更换恢复域，隔离旧授权及不确定操作；不自动恢复所有客户端的登录资格。
原所有者恢复和其他客户端重新批准是独立步骤；身份恢复也不等于拥有所有者的客户端钥匙。
未知短信/电话不得重建为新的待执行操作，旧 outbox 不能通过改绑定强行接入新恢复域。
[原恢复语义与离线矩阵](support-evidence.md#s10)

C09～C12 已完成 WSL2 十五项真实模块恢复矩阵并合并；完整跨库联合恢复和实机恢复仍不能写成普通用户“一键恢复”。
本稿只给出交接要求，不提供设备恢复、分区写入、恢复出厂或整机升级的可执行步骤。

## 应用升级与整机升级不同

已有在已初始化系统中进行签名应用组更新、核对健康和原数据保持的实机记录。
这不等于任何版本都可自动升级，也不等于已具备可用的整机 OTA。
[应用更新证据](support-evidence.md#s11)

申请应用升级时，让负责人核对候选与回退版本的数据格式、身份/授权、转发 outbox 及 Root 安装模式。
只恢复旧二进制或旧业务库可能不兼容，或者丢掉更新后的新记录；不能通过修改 schema、版本号或防降级标记解决。
单独的版本比较工具生成“兼容”结果，不等于完成维护准入或获得升级授权。
后续有限维护准入已有真实签名程序、Root 配置和持锁数据检查记录；维护发起授权仍须单独核对。
[版本比较的离线范围](support-evidence.md#s16)

升级是否完成，应由负责人确认实际选中组、健康状态、准确确认回执和数据保持。
上传包、服务显示运行或页面能打开均不足以单独证明升级成功。
失败时保留候选/回执和数据，由负责人处理，不自行重置回退预算或尝试整机刷写。
[正常应用升级与回退边界](support-evidence.md#s11)

## 热点、Wi-Fi 和蜂窝维护

热点安装材料及权限隔离已有验收，真实手机接入、保存配置、冷启动等仍有独立待验环节。
不要把“已安装”“试连接成功”“保存成功”和“重启后可用”视为同一结果。
网络切换可能中断当前网页，维护前由负责人安排备用连接及收尾方式。
[配网验收范围](support-evidence.md#s12)

普通蜂窝流量测试按本项目当前暂停安排执行，换卡并明确安排前不启用普通 APN 或运行网络探测，
不让 Wi-Fi/USB 失败后隐式回退到蜂窝；不要关闭电话需要的 WWAN/IMS 无线功能。
已做过的单次流量样本不是再次测试的持续授权。
[网络验收范围](support-evidence.md#s13)

## 提交维护问题

可以私下交给负责人：软件交付版本、问题发生时间及所在时区、操作阶段、可脱敏的原操作编号、原样错误提示，
以及是否已经收到短信、对端是否仍在通话等你实际观察到的结果。
不要将“页面说已提交”改写为“对端已收到”，也不要把未观测写成失败或成功。

公开反馈前删去号码、短信/联系人内容、设备身份、SIM/硬件标识、设置码、会话凭据和通知目标中的令牌。
不要上传原始硬件日志、业务数据库、备份、恢复钥匙或维护目录。
界面提供的复制结果仍需按实际内容核对；截图也要遮盖私人字段。
[界面结果范围](support-evidence.md#s02)

本稿不包含私有脚本路径、设备地址、任何人的实际凭据或硬件日志。
最终恢复方案、签名发行包和设备操作由负责人审核并交付。
