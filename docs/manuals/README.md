## 使用前先知道

浏览器保存自己的身份和待核对操作。不要用清除网站数据、无痕窗口或换浏览器来处理“结果未知”。
刷新和查询不能说明上一笔发送没有发生；先核对原操作，再决定后续动作。
详见[身份与操作记录](support-evidence.md#s01)及[未知结果](support-evidence.md#s05)。

“测试拨出”“测试来电”“测试短信”和“一键测试 Bark”会执行通信动作。
只想了解状态时选择“检查状态”；其他测试按[一键测试说明](one-click-tests.md)进行。
本文的操作说明不授予新的短信、通话、推送或蜂窝流量测试授权。

## 怎样理解本稿中的支持范围

- **有限实机验收**：已有记录证明某个具体版本、设备或场景通过；不保证其他硬件、网络或全部故障情形。
- **实现及离线验证**：有真实模块或网页回归证据，尚有实机环节待验。
- **待验证或未提供**：不得按已支持功能使用；由负责人安排后续验收或维护。

每个功能的证据及明确排除项列在[支持范围与证据](support-evidence.md)。
这些标签描述已有记录，本次编写手册没有重新执行通信、设备恢复或更新测试。
REL-01 支持矩阵和正式发行包尚未冻结；最终适用范围以负责人批准的版本为准。
