# 日常使用 · 草稿

[手册目录](README.md) · [结果不确定怎么办](troubleshooting.md)

## 阅读短信

登录后展开“短信 · 日常使用”，点击“刷新收件箱”。点击一条记录的“查看”阅读完整正文；
“下一页”用于继续读取。列表预览不等于已经把每条短信标为已读。
时间未知或发件人缺失时按页面原样理解，不自行补出号码或时间。
已有真实收件及完整中文核验，具体范围见[证据 S03](support-evidence.md#s03)。

若出现“可能相同的短信”，使用“读取候选旧记录”查看两栏内容。
当前记录与候选旧记录保留各自身份；候选仅供核对，不自动合并，也不自动当作当前 SIM 的新消息。
回收站按钮作用于页面明确指出的当前记录。
[候选比较与历史边界](support-evidence.md#s03)

## 发送短信

发送前确认这次发送已经获得你的明确同意；项目测试还需按负责人的安排执行。

1. 在“写短信”中核对“接收号码”和“短信内容”。
2. 点击“发送短信”，在确认提示中再次核对，然后只确认一次。
3. 等待页面结果；需要核实时点“查询发送结果”，查询原操作。
4. 只有结果明确且页面允许时，才使用“完成并清空草稿”。

“已提交发送”不是“接收方已收到”。号码、正文、运营商规则和网络都会影响实际结果。
既有一次真实 10010/CXYE 测试证明了该次发送、回信及中文一致；它不是对所有目标或余额查询的保证。
[发送与回信证据](support-evidence.md#s04)

若看到“未知”“结果未确认”或连接中断，不再点发送、不换新操作编号、不复制到其他浏览器重发。
保留原页面的操作记录，用“查询发送结果”或“核对上次操作”继续核对；仍不明确则交负责人处理。
停止、退出和清空输入都不能撤回已经发出的短信。
[防重及未知结果证据](support-evidence.md#s05)

## 回收站

所有者可在短信详情中选择“移到回收站”，确认后该记录从正常列表隐藏。
要恢复时打开“本地短信回收站”，找到准确记录，选择“恢复”并确认。
提示最近登录不足时先点“重新登录管理短信”，不要换身份或连续重复点击。

回收站是可恢复的本地隐藏：正文仍可能保存在设备数据库和备份中，SIM 上的存储不会因此被清除。
恢复保留原记录编号；其他客户端可能要补同步才能看到变化。
已有正式页面单条删除/恢复闭环，所有独立客户端的补同步尚未全部验收。
[回收站证据](support-evidence.md#s06)

## 日常电话

展开“电话 · 日常使用”。页面有“拨号”“挂断 / 停止准备”“刷新电话”“连接声音”等入口；
浏览器可能要求麦克风权限。未授权麦克风、线路不可用或其他客户端占用时，按页面提示停止，
不要靠换浏览器抢占。[电话入口的实现及边界](support-evidence.md#s08)

有明确通话需求时核对“拨出号码”后点击一次“拨号”。来电只在页面显示当前可操作目标时接听或拒接。
通话结束使用“挂断 / 停止准备”，再核对电话状态。结果未知时查询原电话操作，不创建另一笔拨号。
页面显示结束、收到操作回执和实际完成双向听音是不同的证据；仅显示“已挂断”不能证明通话成功。
[短时双向验收](support-evidence.md#s07)、[未知电话处理](support-evidence.md#s05)

日常拒接、DTMF、长时间通话、多客户端控制竞争和远程声音仍有实机待验项。
本稿介绍入口及限制；参加正式验收前由负责人安排目标、次数和观测。
第一次参加受控通话测试，优先按[一键测试](one-click-tests.md)执行。

## 网络与通知入口

“网络状态、流量与配置”包含读取状态、主动网络测试和配置动作；读取状态与消耗流量的测试要分开。
本项目普通蜂窝流量实测仍按当前暂停安排执行，换卡并明确安排前不要启动相关测试或打开普通数据。
不要为了停数据而关闭电话所需无线功能。[网络证据与限制](support-evidence.md#s13)

“短信转发 · 开关与规则”和“一键测试 Bark”可能向外部服务递送消息。
默认不要为了检查状态而开启转发或发出通知；由负责人另行安排实际目标、内容和次数。
现有合成通知或已交付入口不等于真实新短信转发已全部验收。
[通知范围](support-evidence.md#s14)
