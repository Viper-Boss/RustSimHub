# 常见错误 · 草稿

[手册目录](README.md) · [维护交接](backup-and-maintenance.md#提交维护问题)

先保留原操作记录，记录发生时间和页面提示。以下处理用于判断下一步，不把某个错误直接当成唯一故障原因。

| 现象 | 先怎么做 | 什么时候交负责人 |
|---|---|---|
| 证书警告或设备公钥不匹配 | 停止登录和写入，向可信交付方核对地址、证书与设备身份 | 无法确认匹配时；不要关闭证书校验 |
| 登录失败、401 或 403 | 确认使用原批准浏览器，重新正常登录，核对角色和权限 | 仍失败；401/403 不足以判定只是会话过期 |
| 提示最近五分钟所有者登录 | 用对应重新登录按钮，再核对目标记录；不重复写入 | 登录后仍拒绝，或当前不是所有者 |
| 首次设置不显示或临时设置码失效 | 核对是否已经认领、是否处于负责人安排的窗口 | 不自行删除设置标记或重新初始化 |
| 结果未知、请求超时或连接中断 | 通过“核对上次操作”“查询发送结果”或“查询电话操作”核对原记录 | 仍未知；不更换编号、自动重发或重新拨号 |
| 浏览器存储不可用 | 保留现有数据，停止写入动作，检查浏览器存储限制 | 不清站点数据“修复”；先确认原身份和待处理操作能否保留 |
| 通话未接通、接通但无声 | 核对麦克风授权、页面音量/播放及“连接声音”的提示，先核对原呼叫 | 状态未知或没有声音；不要用连续重拨定位 |
| 短信移到回收站后仍在另一客户端显示 | 在另一客户端补同步/刷新，核对是否同一记录 | 原记录持续不同步；不删除来源或按正文批量合并 |
| 列表读取失败、旧游标不可用或切卡后内容变化 | 重新登录并从列表头刷新；原历史仍按原来源保留 | 刷新失败或来源不明；不把旧历史重新导入为当前消息 |
| 提示不支持、版本不匹配或 501 | 核对负责人交付的版本与支持范围 | 不更改版本字段、关闭鉴权或猜测接口绕过 |
| Wi-Fi 试连、保存或热点结果不明 | 使用原操作的查询入口；保留连接与备用维护通道 | 不反复试连、不将“试连成功”当“已经保存” |

上表依据：[身份 S01](support-evidence.md#s01)、[未知操作 S05](support-evidence.md#s05)、
[回收站 S06](support-evidence.md#s06)、[电话 S08](support-evidence.md#s08)、[配网 S12](support-evidence.md#s12)。
当前 NAS 兼容范围见[S15](support-evidence.md#s15)，接口返回不支持时不猜旧页面字段。

## “未知”不等于“没有执行”

请求可能已经到设备、也可能在返回结果前断线。此时网页保留的原操作是后续查询的依据。
一次刷新、重新登录、关闭标签页或停止按钮都不能证明发送未发生。
不要丢掉记录后另建一笔，也不要把 Unknown 手工改成成功、失败或待发。
[防重证据与待验故障范围](support-evidence.md#s05)

## “没有声音”不等于“没有通话”

可能是浏览器播放或麦克风权限、声音能力、线路未接通或媒体链路问题。
核对原电话状态后按页面允许的动作处理；遇到不确定状态交负责人确认通话是否仍存在。
历史通话行、页面“已挂断”和一次声音能力查询，分别不能替代当前呼叫、真正听音及远端结束证明。
[短通话实机证据](support-evidence.md#s07)、[日常电话未验项](support-evidence.md#s08)

## NAS 显示离线

旧 NAS 页面的离线提示可能来自兼容开关、协议、授权、连接或未适配功能。
先用负责人交付的 RustSimHub 页面只读检查，再按[有限 NAS 范围](support-evidence.md#s15)核对。
不要仅凭一个离线标签判断 SIM 没注册，也不要因此重启基带或启动第二套硬件控制器。

## 什么时候停止自行处理

身份或证书不匹配、原身份材料丢失、旧操作长期未知、更新或恢复失败时，停止新的通信/写入动作并交负责人处理。
维护中保留现有数据和错误证据；不要恢复旧数据库、重建所有者、放宽权限或清空队列来消除报错。
这些限制对应[身份 S01](support-evidence.md#s01)、[恢复 S09/S10](support-evidence.md#s09)和[更新 S11](support-evidence.md#s11)。
