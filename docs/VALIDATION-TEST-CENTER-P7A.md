# P7A 简化测试首页

首页四个入口：检查状态、测试拨出（10010）、测试来电、测试短信（10010/CXYE），共用停止和结果提示。日常电话/短信、账户、网络、配对和手动调试默认折叠。登录、准备和查询由一次任务管理；来电测试仍需另一台手机拨入，麦克风仍须浏览器授权。

旧操作不再要求用户找手动JSON。首页可核对并复制限字段诊断。精确查询匹配后，已结束/取消的回执先持久保存再关闭本地槽；不确定电话仍要求精确旧呼叫终态和新鲜空目录，沿用原归档函数。查询失败、仍活动、身份/ID不匹配或存储失败保留记录；不自动重拨、重发或清设备Unknown。prepared但客户端已标记提交的记录仍保留，不按“未发送”推断。

短信测试固定准备10010/CXYE，显示号码和正文并确认一次。旧草稿可保存在本机，通过短信区按钮恢复；不覆盖另一份已保存草稿。提交标记仍先于唯一HTTP提交，停止/注销不会越过后续提交边界。已发送短信无法撤回，停止只阻止尚未发生的动作。

13组Node网页夹具通过。新增真实生产app接线覆盖自动登录、布局ID唯一/默认折叠、防重恢复、错误ID/活动/无结束证明、归档存储失败、安全复制、一次短信提交、草稿保存和停止/注销竞争；均为合成输入，不是实机短信或听音证据。

固定源码构建、原信任签名升级和设备静态资源验证待本轮补齐。当前未更改Root服务、无线配置或分区；旧浏览器控制通道故障不通过其他UI方式绕过。
