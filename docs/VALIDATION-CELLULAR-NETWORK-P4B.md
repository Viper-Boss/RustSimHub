# P4B：移动蜂窝、网络诊断与月流量守卫

2026-10-22。用户换入有流量的中国移动卡并授权测试，随后要求测试完成关闭流量、换回原卡。本轮完成普通数据连通、后台网络模块及真实月限额测试。整体由75.5增至 **76.5/100**，P4增加1点；R11仍有未完成项，不代表完整蜂窝/远程验收通过。

## 实现与边界

管理页面新增接口状态、IPv4/IPv6、网关、DNS、已连接APN、运营商/注册/制式、信号、支持/允许频段、服务小区、TAC/PCI、EARFCN及RSRP/RSRQ。可由EARFCN推导当前LTE频段和上下行频率；本次设备未提供带宽，明确显示缺值。新增真实收发速率曲线、按SIM分开的月统计、限额开关、额度和重置日，以及明确授权后执行的定量网络测试。设计与接口见 [网络模块](network-diagnostics.md)。

Root服务只持有NET_ADMIN，固定读取nmcli/mmcli/nft，不提供任意命令接口。Core验证网络权限和近期owner登录，Edge测试前后核验会话；普通状态权限不获得小区信息。DNS与HTTPS首次绑定选定接口和源地址，失败不换出口；TLS保持系统CA与主机名验证。网页退出/隐藏及迟到回复不会恢复已清空的数据。

| 项目 | 实际证据与结果 |

| 实际网页与接口 | HTTPS取得页面及network.js并核对源码；实际Edge UID985、空capability下成功绑定wwan0的DNS UDP和HTTPS TCP；未更改SSH转发限制 |

| 月账本 | 板级接口字节计数一直为0，因此使用独占nftables具名IP计数器；最终接收1,109,944、发送42,184、合计1,152,128字节，账本重启前后完全一致 |

| 守卫重启 | 停止前先阻断并保存，替换/启动后实际非零月统计保持；NetworkManager主PID及启动时间完全不变 |
| 实际SIM格式 | 移动卡标识含ASCII字母，原纯数字限制会拒绝；统一为8–32位ASCII字母/数字规范化，生产Core隔离只读观察达到ready；不公开卡号或私有摘要 |
| 测试清理 | 删除临时gsm连接、停止临时Core/Edge/观察者和清理定时器；恢复限额默认关闭、10GiB/每月1日，但普通数据保持断开且没有gsm自动连接profile；PCM关闭，无新电话/短信 |

月统计为本机IP层估算，运营商账单为准。每5秒检查点可能留下掉电窗口；限额开启且计量不确定时阻断普通数据，必须由所有者核对后显式接受差异。最多3200条/400天，私有账本上限修正为1MiB以覆盖保留记录；不清零历史来绕过限额。
