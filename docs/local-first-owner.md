# 显式本地首个所有者窗口

实现中，尚未实机/浏览器验收，不增加完成百分比。

普通生产运行模式仍拒绝初始化所有者。可信安装/维护入口可显式启动
`--serve-local-setup SOCKET EDGE_UID STATE_DIR IDENTITY_DIR PRIVATE_CODE_FILE`。
代码文件为 Core UID 所有、严格私有、不可链接的 32 字节随机值。安装器应经可信 USB/维护路径向用户交付其 64 位小写十六进制形式及设备公钥，不使用网络 identity 回应作为公钥核对的替代品。

- 启动时库必须没有任何 principal，包括已撤销 owner。既有所有者不能开启此模式，不能把数据库内容或所有权远程重置。
- 窗口 5 分钟，最多 16 次码校验；本地进程内单调时钟，无网络时钟或用户传入时间。每次 challenge/finish 均校验码，使用上游 HMAC 的固定长度恒定时间 tag 验证。
- challenge 使用已有 exact-byte 设备签名 transcript，绑定设备 pin、浏览器 Ed25519 公钥、owner/全权限、bootstrap 用途、代次零及当前随机实例。只允许该窗口最后一个 challenge 完成。
- 签名必须证明浏览器持有自己的私钥。初始化事务仍要求 principals 为空；成功后窗口不可再次使用，秘密内存清零，后续初始化拒绝。
- `/api/v2` 继续严格 TLS/Host/Origin/内容类型/版本头/有界请求，既有 IPC UID 门禁不变。没有 owner 也不能仅凭来源 UID 获得权限。设置码不放 URL、identity、日志或浏览器 IndexedDB。
- 浏览器在设备报告可用窗口时显示首次设置；私钥仍不可导出、仅存本机 IndexedDB。登录能核验已签名的 client 或 owner transcript；选择期待的形状不能替代签名、公钥与用途检查。首次设置回包丢失时可正常签名登录核验结果，不自动重新初始化。

此模式仅观察短信/呼叫，禁止电话/短信写入，也不启用网络试连接/蜂窝数据。窗口结束后正式切换普通运行模式由安装/服务管理完成；当前还没有自动开机安装。
