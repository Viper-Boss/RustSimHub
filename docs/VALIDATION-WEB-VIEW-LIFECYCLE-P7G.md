## 发现与修正

旧页面的通话列表在每次回复后直接追加行和可控制呼叫，未检查列表是否已刷新；通话详情也没有列表代次检查。历史来源、分页和详情的迟到回复可能覆盖新选择，旧请求失败还可能清空新来源的内容。注销时通话详情未清空。

新增每类分页请求的代次和在途检查。同一列表重复翻页明确拒绝；显式刷新可取代旧请求，旧请求完成后不能释放新请求的在途状态。短信和通话翻页失败保留原游标，能够重新查询同一页。被替代的列表刷新会返回失败，使事件补同步不提前提交游标。

通话详情绑定列表代次及详情请求编号；过期回复不显示，也不发送通知已读请求。刷新时清除旧通话详情和可控制呼叫，注销时清除详情并失效所有旧列表任务。历史来源/记录类型变化时立即清空旧视图，即使另一个页面动作仍在等待；分页与详情同时核对代次、来源和类型，旧成功或失败回复都不能覆盖、清空新视图。

没有改变Core权限、租约、短信发送、防重或网络策略；不自动重试副作用操作。
